# 简体中文覆盖与核验清单

本清单记录已实现的范围和仍需完成的工作。翻译表存在条目不代表已用每个游戏版本、改版样本或实机逐项核验。

## 应用界面与语言

- `ZH_CN` 可在语言设置中选择，并沿用现有设置持久化机制。自动模式下，简体中文设备优先于英文 ROM，其他非英文 ROM 仍优先使用游戏语言。
- 现有应用翻译表的 1,349 条目均有非空中文；`scripts/check_translations.py --require-zh` 检查覆盖与占位符。这不证明所有硬编码的可见文字或动态内容都已纳入翻译表，仍需逐屏盘点。
- 已检查中文字体回退并在 Fusion Pixel 子集中补充 U+692A。已渲染 Thor 尺寸的主要界面和部分长文本；尚未完成 Duo Lite、小尺寸双屏、单屏、旧版 Android 的全面渲染及实机验证。

## 内置攻略

- `scripts/check_zh_guides.py --require-all` 检查现有攻略翻译表及占位符；`GuideTranslationsTest` 审计已登记攻略的页面标题和静态数据并生成 `app/build/guide-zh-missing/` 报告。
- 审计依赖测试枚举范围：BOSS 动态队伍以空存档和地图组 0 至 80 取样。动态文本、其他存档状态和未来新增内容仍需检查。尚不能据此宣称所有改版版本或样本已核验。
- 无可靠译名的改版人物与地点可能保留原名。无法识别的攻略文字显示原文并标记 `未译`；已经包含汉字的原文保留。

## 游戏资料

- 图鉴物种名称表来自 [PokeAPI 固定提交的 pokemon_species_names.csv](https://github.com/PokeAPI/pokeapi/blob/6b8db7f3cb31cfaa37cb74e5c3edff124bcba5ce/data/v2/csv/pokemon_species_names.csv)，覆盖全国图鉴编号 1 至 1025。来源文件 SHA-256、许可及生成方式记录在 `scripts/gen_zh_species.py` 和 `NOTICE` 中。三处简体字修正的官方来源记录在生成脚本中；其余条目尚未逐条与官方来源独立复核。
- 图鉴只在全国图鉴编号与 ROM 原名称都匹配时显示该表译名；不匹配的名称（包括汉字名称）保留原文并标记 `未译`。玩家昵称不经该函数改写。该匹配仍需对每个支持的游戏和改版版本使用实际样本逐项验证。
- 标准属性标签在显示时翻译，逻辑使用原有属性标识。非标准属性和改版属性仍需逐项核验。
- 队伍和战斗中的物种名称、招式、道具、特性、地点、图鉴描述及改版重写效果尚未全面适配或逐项核验；这些显示路径也尚未全部实现未知内容的 `未译` 标记。不能依据全国图鉴编号推断改版内部编号，也不能把未经核验的标准描述套用于改版。
- 本地样本的只读 SHA-1 盘点：Unbound 2.1.1.1 中文版、Radical Red 4.1 中文版、水银 FC 1.33、Quetzal Alpha 9 v0 中文版及 Team Rocket 中文版 3.04 与 `Poller.kt` 中的配置哈希一致。Elite Redux 2.65 beta2 中文调试版只在 `CjkTables.kt` 找到对应字表哈希，不能据此认定有匹配的运行配置。这些哈希检查只确认文件身份。可选测试 `TeamRocketCnDecodeTest` 已从本地西火中文样本的第 13 号道具表项解码出预期名称；其余条目的中文资料映射、游戏效果和动态显示仍未逐项验证。运行样本测试时以 `POKEDAISY_SAMPLE_DIR` 指定本地目录，ROM 不进入仓库。


## 帮助手册

- 24 页共享手册中，`welcome.md`、`install.md`、`party.md`、`bag.md`、`battle.md`、`map.md`、`dex.md`、`guide.md`、`trainer-card.md`、`achievements.md`、`fast-forward.md`、`cheats.md`、`nuzlocke.md`、`saves.md` 和 `hud.md` 已有中文页面；其余 9 页保留英文并标记 `未译`。中文页与英文源文件通过 SHA-256 关联：英文变动后，旧译文会回退为标记的英文原文，直到重新校对。
- 网站中文页面、中文 API 和应用离线数据由同一份手册生成。应用内置已翻译页面的图片，搜索支持中文短语。现有插图是英文界面截图，尚需制作中文截图。
- 在 `website/` 运行 `node scripts/generate-zh-manual.js` 更新离线数据和已翻译页面的图片。`npm test` 检查链接、离线副本、图片散列、中文搜索及已有译文的源文件版本。
